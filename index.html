Política de Privacidad de TAURBUILDING: Gym y Progreso

Última actualización: 10 de octubre de 2026

Esta Política de Privacidad explica cómo TAURBUILDING: Gym y Progreso, desarrollada por MigueWhitetower, gestiona la información relacionada con el uso de la aplicación móvil para Android.

1. Responsable de la aplicación

Plataforma: Android / Google Play

2. Información que recopila la aplicación

TAURBUILDING está diseñada para funcionar principalmente de forma local en el dispositivo del usuario.

La aplicación puede almacenar localmente información introducida por el usuario relacionada con sus entrenamientos, incluyendo rutinas, ejercicios, series, repeticiones, pesos, tiempos de descanso, objetivos, registros personales, progreso y otros datos relacionados con el entrenamiento.

Estos datos de entrenamiento se almacenan en el dispositivo y no se envían a un servidor propio de TAURBUILDING.

3. Cuentas de usuario

TAURBUILDING no requiere que el usuario cree una cuenta para utilizar sus funciones.

La aplicación no solicita directamente nombre, dirección postal, número de teléfono ni contraseña para crear una cuenta.

4. Datos de ubicación

TAURBUILDING no recopila ni almacena la ubicación precisa del usuario para proporcionar sus funciones principales.

5. Notificaciones

La aplicación puede utilizar notificaciones locales para funciones relacionadas con el entrenamiento, como avisos del temporizador y del tiempo de descanso.

Estas notificaciones se utilizan para proporcionar funcionalidades de la aplicación y no para enviar publicidad personalizada.

6. Compartición de datos

TAURBUILDING no vende, alquila ni comparte con terceros los datos de entrenamiento almacenados localmente por el usuario.

La aplicación no utiliza estos datos de entrenamiento para publicidad personalizada.

7. Exportación e importación de datos

La aplicación puede permitir al usuario exportar o importar datos de entrenamiento mediante archivos JSON o documentos relacionados con su progreso.

Cuando el usuario exporta un archivo, este queda bajo su control. El usuario decide dónde almacenarlo, compartirlo o enviarlo.

8. Seguridad de los datos

Se aplican medidas razonables para proteger la información gestionada por la aplicación. No obstante, ningún método de almacenamiento electrónico garantiza una seguridad absoluta.

9. Eliminación de datos

Los datos almacenados localmente pueden eliminarse mediante las funciones disponibles en TAURBUILDING o mediante la eliminación de los datos de la aplicación desde el dispositivo.

10. Servicios de terceros

TAURBUILDING no utiliza un servidor propio para recopilar los datos de entrenamiento del usuario.

Su funcionamiento puede estar sujeto a las políticas y servicios del sistema operativo Android y de la plataforma de distribución Google Play.

11. Privacidad de menores

TAURBUILDING no está dirigida específicamente a menores de edad y no recopila deliberadamente información personal de menores.

12. Cambios en esta política

Esta Política de Privacidad podrá actualizarse para reflejar cambios en la aplicación, sus funciones o los requisitos legales aplicables.

La fecha de la última actualización se indicará al principio de esta página.
