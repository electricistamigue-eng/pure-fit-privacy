Política de Privacidad de Pure Fit Miguel

Última actualización: 17 de agosto de 2026

Esta Política de Privacidad explica cómo Pure Fit Miguel gestiona la información relacionada con el uso de la aplicación móvil.

1. Responsable de la aplicación

Aplicación: Pure Fit Miguel

Para cualquier consulta relacionada con esta Política de Privacidad, el usuario puede utilizar los datos de contacto disponibles en la ficha oficial de Pure Fit Miguel en Google Play.

2. Información que recopila la aplicación

Pure Fit Miguel está diseñada para funcionar principalmente de forma local en el dispositivo del usuario.

La aplicación puede almacenar localmente información introducida por el usuario relacionada con sus entrenamientos, incluyendo rutinas, ejercicios, series, repeticiones, pesos, tiempos de descanso, objetivos, registros personales, progreso y otros datos relacionados con el entrenamiento.

Estos datos se almacenan en el dispositivo y no se envían a un servidor propio de Pure Fit Miguel.

3. Cuentas de usuario

Pure Fit Miguel no requiere que el usuario cree una cuenta para utilizar las funciones de la aplicación.

La aplicación no solicita directamente nombre, dirección postal, número de teléfono, contraseña ni otros datos personales para crear una cuenta.

4. Datos de ubicación

Pure Fit Miguel no recopila ni almacena la ubicación precisa del usuario para proporcionar sus funciones principales.

5. Notificaciones

La aplicación puede utilizar notificaciones locales para funciones relacionadas con el entrenamiento, como avisos del temporizador y del tiempo de descanso.

Estas notificaciones se utilizan para proporcionar funcionalidades de la aplicación y no se utilizan para enviar publicidad personalizada.

6. Compartición de datos

Pure Fit Miguel no vende, alquila ni comparte con terceros los datos de entrenamiento almacenados localmente por el usuario.

La aplicación no utiliza los datos de entrenamiento del usuario para publicidad personalizada.

7. Exportación e importación de datos

La aplicación puede permitir al usuario exportar o importar determinados datos de entrenamiento mediante archivos, como archivos JSON o documentos relacionados con el progreso.

Cuando el usuario exporta un archivo, dicho archivo queda bajo su control. El usuario es responsable de decidir dónde almacena, comparte o envía estos archivos.

8. Seguridad de los datos

Se aplican medidas razonables para proteger la información gestionada por la aplicación. No obstante, ningún método de almacenamiento electrónico puede garantizar una seguridad absoluta.

9. Eliminación de datos

Los datos de entrenamiento almacenados localmente pueden eliminarse mediante las funciones disponibles en la propia aplicación o mediante la eliminación de los datos de la aplicación desde el dispositivo.

10. Servicios de terceros

Pure Fit Miguel no utiliza un servidor propio para recopilar los datos de entrenamiento del usuario.

El funcionamiento de la aplicación puede estar sujeto a las políticas y servicios del sistema operativo y de la plataforma de distribución, como Google Play y Android.

11. Privacidad de menores

Pure Fit Miguel no está dirigida específicamente a menores de edad y no recopila deliberadamente información personal de menores.

12. Cambios en esta Política de Privacidad

Esta Política de Privacidad puede actualizarse cuando sea necesario para reflejar cambios en la aplicación, en sus funciones o en los requisitos legales aplicables.

La fecha de la última actualización se indicará al principio de esta página.

13. Contacto

Si tienes alguna pregunta sobre esta Política de Privacidad o sobre el tratamiento de datos en Pure Fit Miguel, puedes utilizar los datos de contacto proporcionados en la ficha de la aplicación en Google Play.
